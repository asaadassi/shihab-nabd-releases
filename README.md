# Shihab Nabd (نبض) — الإصدارات

حمّل أحدث نسخة من صفحة [الإصدارات](https://github.com/asaadassi/shihab-nabd-releases/releases/latest):

- `shihab-nabd-x.y.z-windows-x64-installer.exe`: إضافة OBS لمراقبة البث: إحصاءات مباشرة ومؤشرات شريط الحالة وتنبيهات صامتة عن الاتصال.

كل مثبّت يرافقه ملف توقيع `.sig` وملف بصمات `SHA256SUMS.txt`. أغلق OBS قبل التثبيت. تحتاج Shihab Source Record 2.1.0 أو أحدث إن كانت مثبّتة.

---

Shihab Nabd (نبض) releases: an OBS plugin that watches your broadcast: live stats, status bar readings and silent connection alerts. Download the latest version from the [Releases](https://github.com/asaadassi/shihab-nabd-releases/releases/latest) page. Every installer comes with a `.sig` signature and `SHA256SUMS.txt`. Close OBS before installing. Needs Shihab Source Record 2.1.0 or newer when it is installed.

This repository holds releases only; the source code (GPL) is available on request from support@shihab.app.
